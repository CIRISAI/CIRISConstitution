# The Digest

**What this is.** The short versions: the executive summary, the plain-language rules for a person who uses an agent, the operator digest for a person who runs a node or answers for an agent, and the guarantees table with its status markers.

**Whom it binds.** Nobody. A digest is a derivative: each rule names the register row or the binding section it summarises, and each promise the register rows that keep it, and when a digest and a section disagree, the section is right and the digest is a defect.

**What it promises.** Present tense only for what ships. Every promise line carries a marker stamped from the register: works today, being built with its ticket, a rule with no code yet, modelled, staged with its ticket (the register row exists and the wire does not yet keep it), or in code with no register row yet (shipped, with no row to pin it to).

**What it leaves out.** Everything else. Read it first; read the volume it points to when you need the rule.

**Where the rest lives.** The eight other volumes, and the full edition they are cut from, released as guidance.
